## 摘要

声骸评价包含两个不同的问题：一是词条组合对某一角色的通用质量，二是该声骸在特定配装中的实际替换价值。本文介绍本站发布的《鸣潮》单角色声骸评分器，以角色相关的静态系数评价词条质量，以当前面板驱动的伤害因子比较换装收益，并讨论暴击上限、伤害类型权重与条件型套装效果对决策的影响。本文给出模型定义、可复算的数值示例与适用边界。所述结果属于简化模型下的条件性估计，不等同于队伍循环 DPS，也不构成对全角色机制的实测验证。

**关键词：** 鸣潮；声骸评价；边际收益；期望伤害；多属性决策

## 1. 问题定义与研究范围

固定双暴分能够快速描述声骸的部分质量，但无法独立回答换装问题。相同的暴击率词条，在暴击不足与暴击接近上限时，可能产生明显不同的收益；攻击、生命或防御词条的价值，也取决于角色的主要倍率属性与现有面板。因而，本工具将“声骸品质评价”与“配装条件下的收益评价”分别建模。[1]

工具的分析单位是**单角色、给定共鸣链和装备效果假设下的一套五只声骸**。它接受当前静态面板、角色、链数、专武被动与合鸣套装配置，输出单只词条评分、整套毕业度、候选替换提升与局部改进建议。攻击类型权重来自角色机制数据库，部分角色随链数改变。[1][2]

本文初版对应 2026 年 9 月 17 日的实现快照，并于 2026 年 10 月 25 日按当时的实现更新（见文首更新记录）。后续版本若修改角色数据或计算规则，应以工具实际版本及更新说明为准。本文是工程方法说明，并非经过同行评审的游戏伤害研究论文。

## 2. 符号约定与基本假设

| 符号 | 含义 | 约定 |
| --- | --- | --- |
| E | 当前五只声骸的集合 | 包含主词条、固定主词条与副词条 |
| E′ | 替换后的声骸集合 | 仅替换指定位置，其他配置保持一致 |
| S | 战斗态主要倍率属性 | 根据角色取攻击、生命或防御 |
| r、d | 暴击率、暴击伤害倍率 | 75% 暴击率记为 0.75；250% 暴伤记为 2.50 |
| wₖ | 第 k 类伤害的模型权重 | 非负，归一化后总和为 1 |
| B、bₖ | 通用加成与对应类型加成 | 以小数表示；B 合并全局与属性伤害加成 |
| A、aₖ | 全局加深与第 k 类伤害的加深 | 以小数表示；与 B、bₖ 分属不同乘区 |
| F(E) | 声骸配置对应的伤害因子 | 用于相对比较，不是实际伤害数值 |

比较建立在三个主要假设上：第一，玩家录入的是与当前声骸一致的静态面板；第二，除明确重算的装备条件外，两套配置沿用相同的角色机制与输出构成；第三，未进入模型且两侧相同的乘区可在比值中约去。第三项仅在相关因素确实不随换装变化时成立。

## 3. 静态评分：描述词条质量

对角色 c，记第 j 条副词条的数值为 vⱼ、对应静态系数为 a꜀,ⱼ，则单只声骸评分为：

<div class="research-equation">Q꜀(e) = 100 × Σⱼ(a꜀,ⱼ · vⱼ) / M꜀</div>

其中 M꜀ 为该角色五种互不重复、满档副词条的最高加权总和。该归一化使 100 分对应此静态规则下的理论最优五条组合，而不是“100% 实战输出”。评分框架参考 WuwaEchoTool。[1][3]

自 2026-10-25 起，系数 a꜀,ⱼ 不再人工设定，而是由第 4 节的伤害因子 F 在一个固定的**毕业参考面板**上求偏导得到，并以“1% 主要倍率属性 = 1”归一：

<div class="research-equation">a꜀,ⱼ = (∂ ln F / ∂vⱼ) ÷ (∂ ln F / ∂p主)</div>

| 参考面板项 | 取值 |
| --- | --- |
| 主要倍率属性 | 基础值 × 2.5（攻击 1000→2500；生命 16000→40000；防御 1100→2750） |
| 伤害加成合计 | +100% |
| 战斗态暴击率 / 暴击伤害 | 80% / 280% |
| 角色效果 | 计入当前链数的暴伤、增伤与加深；暴击率不叠加 |

在该面板上，1% 主要倍率属性带来 1/250 的相对提升，于是各类系数为（sₖ 为第 k 类伤害在参考面板上的实际占比）：

| 词条 | 系数 |
| --- | --- |
| 暴击率 | 2.5 × (d − 1) / C(r,d) |
| 暴击伤害 | 2.5 × r / C(r,d) |
| 主要倍率属性百分比 | 1 |
| 对应固定属性 | 100 / 基础值：固定攻击 0.1；固定生命 0.00625；固定防御 0.091 |
| 普攻、重击、技能、解放伤害加成 | 2.5 × sₖ / (1 + B + bₖ) |
| 属性伤害加成（仅主词条） | 2.5 × Σₖ sₖ / (1 + B + bₖ) |
| 共鸣效率 | 0.5（不进入伤害因子，沿用经验约定） |
| 不相关属性 | 0 |

以锁暝为例：

| 词条 | 0 链 | 2 链（暴伤 +40%） | 3 链（另加普攻加深 30%） |
| --- | --- | --- | --- |
| 暴击率 | 1.844 | 1.993 | 1.993 |
| 暴击伤害 | 0.820 | 0.725 | 0.725 |
| 攻击百分比 | 1 | 1 | 1 |
| 普攻伤害加成 | 0.955 | 0.955 | 1.010 |
| 共鸣解放伤害加成 | 0.245 | 0.245 | 0.199 |

0 链与 2 链的暴击系数与 WuwaEchoTool 新版模型公布的数值一致。[3]参考面板是对“典型毕业配装”的约定，暴击与暴伤之间的相对价值会随这一约定变化。暴击率之所以不叠加链数加成，是因为玩家通常会把战斗态暴击配平到约 80%；若直接叠加，带暴击链的角色会被算到暴击上限，使暴击词条被错误地判为零价值。对于既有角色（WuwaEchoTool 来源），其逐链伤害占比已折算链效果，因此只调整乘区，不再重复调整占比。[2]

表中百分比词条按游戏显示的百分点数值计分，例如 6.3% 暴击率使用 6.3。[5]整套毕业度进一步纳入主词条与固定主词条，并按当前各位置 COST 对应的理论满配得分归一化。评级方面，单只声骸为 ≥80 S、≥65 A、≥50 B、≥35 C、其余 D（最高 S）；整套为 ≥90 大毕业（SSS）、≥80 中毕业（SS）、≥70 小毕业（S）、≥60 接近毕业（A），其余依次为 B、C、D。

这套分数的优点是稳定、易比较。其限制同样明确：系数在参考面板而非玩家实际面板上求得，它不读取当前暴击是否溢出，也不判断充能是否已满足循环需求。共鸣效率的 0.5 是静态评价约定，不是由伤害公式推导出的固定 DPS 权重。**高分声骸不必然带来正的换装收益。**

## 4. 伤害因子与边际收益

### 4.1 期望暴击乘区

在可暴击伤害共享同一暴击面板的简化条件下，暴击期望乘区为：

<div class="research-equation">C(r,d) = 1 + min(max(r,0),1) · (d − 1)</div>

当 0 &lt; r &lt; 1 且其他变量固定时，其对暴击率和暴击伤害的对数敏感度分别为：

<div class="research-equation">∂ ln C / ∂r = (d − 1) / C<br>∂ ln C / ∂d = r / C</div>

这说明双暴的价值依赖已有面板。[6][7]暴击率达到上限后，继续增加暴击率不再提高本模型的暴击期望。微分表达只解释局部趋势；实际词条替换采用有限变化的完整比值计算，不能在跨越上限时直接线性外推。

### 4.2 伤害类型加权

在属性与各乘区处于有效范围内时，当前代码的主要形式可写为：

<div class="research-equation">F(E) = S(E) · C(r(E),d(E))<br>× Σₖ wₖ · [1 + B(E) + bₖ(E)] · [1 + A(E) + aₖ(E)]</div>

类型 k 包括普攻、重击、共鸣技能、共鸣解放与其他伤害。“其他”在当前实现中不获得这四种类型词条的加成。加深与伤害加成分属不同乘区：同一乘区内相加，不同乘区相乘。自 2026-10-25 起，游戏描述为“加深”的链效果与武器效果（例如锁暝 3 链的普攻伤害加深 30%、心的专武的共鸣技能伤害加深 36%）计入 aₖ，不再并入 bₖ；否则会稀释对应类型伤害加成词条的边际价值。以锁暝 3 链为例，一条 9% 普攻伤害加成的模型收益由约 3.2% 修正为约 3.8%。该模型使用统一主要倍率属性和统一暴击乘区，不逐段展开技能倍率、动作时长与特殊伤害机制。[1][6][7]

数据库权重是对输出构成的简化表达。若权重来源本身是某一参考配装下的最终伤害占比，将其固定用于其他配置可能带来偏差；因此不应把该因子解释为逐技能模拟器或实战总伤害预测。

### 4.3 替换比较与面板重建

设候选声骸替换位置 n，收益定义为：

<div class="research-equation">G = [F(E′) / F(E) − 1] × 100%</div>

工具根据当前面板与当前声骸反推非声骸底座，再重建候选配置。以攻击属性为例，代码使用的有效基础量可概括为：

<div class="research-equation">S₀,eff = (S面板 − f声骸) / (1 + p声骸 + p非声骸)<br>S(E′) = S₀,eff · (1 + p声骸′ + p非声骸 + p战斗) + f声骸′</div>

p 表示百分比属性，f 表示固定属性。这里的 S₀,eff 是模型反推的有效量，并不保证等于角色与武器的真实基础属性之和。未被正确录入或建模的非声骸属性可能影响换装估计。需要说明的是，当前版本界面不提供 p非声骸 的单独录入，实现中该项恒为 0：不来自声骸的百分比加成会被折入反推的 S₀,eff，这会使主倍率百分比词条的边际收益被轻微高估，属于已知的模型保留项。完整录入后，页面会锁定底座以联动模拟面板；重新输入实际面板时必须保持其与装备记录一致。[1]

对带充能阈值的套装，计算应依据每一被评估配置重新判断条件。当前实现已将候选声骸聚合值传入套装判断，避免在替换后沿用原配置的触发状态。但这不代表所有角色特有转化规则与阈值均已建模。

## 5. 可复算示例：双暴价值与上限

以下为依据第 4.1 节公式构造的控制变量算例，**不是游戏实测数据，也不是完整声骸替换实验**。固定其他乘区与伤害类型，仅独立增加一条属性，不考虑被替换词条的损失。

| 初始暴击率 / 暴伤 | 独立变化 | 初始 C | 变化后 C | 相对提升 |
| --- | --- | --- | --- | --- |
| 75% / 250% | 暴击率 +6.3 个百分点 | 2.12500 | 2.21950 | 4.4471% |
| 75% / 250% | 暴伤 +12.6 个百分点 | 2.12500 | 2.21950 | 4.4471% |
| 98% / 250% | 暴击率 +6.3 个百分点 | 2.47000 | 2.50000 | 1.2146% |
| 98% / 250% | 暴伤 +12.6 个百分点 | 2.47000 | 2.59348 | 4.9992% |

按 0 链参考面板的静态系数，6.3 × 1.844 ≈ 11.62，12.6 × 0.820 ≈ 10.33，即在 80% / 280% 的参考面板上暴击率略占优；而在上表第一组面板（75% / 250%）中两者的实际收益恰好相等，第二组面板中又明显分离。静态系数只代表参考面板，这正是需要并列展示静态评分与换装收益的原因。

复算时先将暴击率限制在 100%，再代入 C，并计算 C新 / C旧 − 1。若要评价真实换装，还需同时加入原声骸损失、候选主副词条变化与装备条件变化。

## 6. 局部改进建议与使用流程

推荐器枚举两类局部动作：将已有目标词条提升至满档；或在尚无目标词条的声骸上，将一条已有副词条替换为目标词条的平均数值。每个方案均复制整套声骸并重算 F，随后按正收益排序。因此，已建模的暴击上限与套装阈值能够进入具体比较。[1]

这里的“平均档”实际采用档位数值的算术平均，它可能不是游戏内可出现的单个档位，也不意味着已按掉落概率求期望。[5]建议表示模型中的局部改善方向，不是游戏内可以指定执行的洗练操作，更不是获得该声骸所需资源的预测。当前建议集合亦未把共鸣效率作为独立搜索目标，因此不能据“暂无升级”推出全局最优。

实际使用可按以下步骤进行：

1. 在“我的角色”或“配装计算”中选择角色与共鸣链（已有存档会自动载入，修改自动保存），核对专武被动和套装配置是否符合实际。
2. 录入五只已装备声骸（可用“截图导入”识别声骸详情截图）及当前静态面板，确保二者对应同一状态。
3. 查看“整套毕业度”与“下一步提升”；如有新声骸，在“对比新声骸”中选择替换位置并填写，先确认 COST 提示与词条合法性。
4. 优先阅读替换提升与“下一步提升”，再结合单只评分判断养成方向。
5. 对相近结果，结合充能循环、操作习惯与实战稳定性复核，不仅凭小数点后的差异决定去留。

界面会处理手动选择的重复副词条，并对当前或替换后总 COST 超限显示警告。超限配置仍可继续计算，故出现数值不代表配置可以在游戏内装备。

## 7. 数据来源、可复现性与局限

角色目录、角色机制与套装效果分开维护。实现中的置信度标签区分实测、攻略推导与前瞻估计；这些标签描述数据来源口径，不表示本文已独立验证全部角色。角色目录引用库街区 WIKI，既有角色机制与评分方案参考开源 WuwaEchoTool；具体效果以本项目对应版本数据记录为准。每只声骸可出的合鸣套装取自游戏数据表，用于在选择套装后筛选声骸。[2][3][4][8]

为复现一个换装结果，应保存：计算器版本、角色与链数、当前面板、武器和套装开关、五只声骸的完整词条、候选配置及替换位置。仅报告“某声骸提升 3%”而不提供这些条件，无法形成可比较的结果。

本工具当前主要存在以下边界：

- **队伍与时间维度缺失。** 未模拟队友增益覆盖、输出窗口、动作顺序及循环时长，结果不是队伍 DPS。
- **角色机制简化。** 单一倍率属性、固定输出构成及统一暴击乘区不足以完整表达混合倍率、特定技能独立暴伤和部分特殊伤害。
- **触发条件采用约定状态。** 部分效果按触发或满层口径处理，不包含真实覆盖率。
- **充能的循环价值未展开。** 除已编码的属性阈值外，不将充能直接折算为通用伤害收益。
- **验证范围有限。** 本文提供公式算例和实现说明，未建立覆盖全部角色、链数与套装的实机误差统计，不能宣称具有某一统一准确率。

## 8. 结论

静态评分适合概括角色相关的词条质量，面板驱动的有限差分比较适合回答具体换装问题。两者应相互参照，而不能互相替代。本站评分器的目标，是把词条评价中的条件和假设显式呈现，使玩家能够解释一个推荐结果，并在模型能力之外保留实战判断。

后续值得优先推进的工作包括：增加可复现的机制测试案例，核对面板与战斗增益的边界，细化特殊角色公式，并在必要时扩展输出循环模型。这些是改进方向，不是当前版本已经完成的功能。
