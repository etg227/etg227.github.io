DMM

DMM GAMES

按进程与域名识别 DMM GAMES PLAYER 及相关游戏流量，未匹配流量保持本地直连。

GBF

Granblue Fantasy 专项优化

实时/API/登录流量优先走日本出口；静态 Akamai 素材使用自适应最快路径，并支持安全的本地 CAS 缓存。

NIKKE

NIKKE

Windows 客户端按进程分流；macOS 规则在验证可靠的原生/网页路径前保持保守禁用。

CACHE

GBF 本地资源缓存

通过专用 Chrome 与 DevTools 接口缓存明确允许的官方静态素材，不安装根证书，不缓存登录、Cookie、账号 API 或带授权信息的响应。重复素材优先从本机读取，减少重复网络流量。

DEV

Local Clash 测试

开发模式可让 ACG Relay 负责 TUN 与游戏分流，再把命中的游戏连接交给本机 Clash SOCKS5 作为临时日本出口。

FAQ

ACG Relay 是普通 VPN 吗？

不是。默认策略是 Direct，仅匹配的游戏流量进入 Relay；浏览器、Discord、Steam 其他游戏等不会因为开启加速而全部改走日本出口。

为什么 GBF 还要本地缓存？

GBF 会反复加载大量图片、声音、脚本和字体。对明确、不可变的静态资源做本地缓存，可以降低重复流量并改善二次访问的一致性。缓存不处理账号登录与私密 API。

现在没有日本 VPS 能测试吗？

可以。开发模式支持本机 Clash/Mihomo SOCKS5 上游，用于验证 TUN、域名/进程规则、GBF 专项路径与缓存。正式用户版本会隐藏该开发入口。

更新从哪里发布？

版本发现使用本博客的静态更新清单；正式安装包可以托管在 GitHub Releases 或其他下载 CDN。博客只保存公开发布信息，不保存会员数据库或节点密钥。
