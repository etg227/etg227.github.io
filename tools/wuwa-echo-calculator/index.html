Reference / 公式依据

  1. Wuthering Tools — Info / damage formula：属性面板、Damage Bonus、Amplify、暴击、防御与抗性乘区的社区实测计算口径。
  2. 鳴潮 Wiki* — ダメージ計算式（页面更新 2026-08-13）：攻击力公式、不同伤害乘区、暴击期望与 1:2 推导、防御/耐性说明。
  3. Prydwen — Echoes Stats：声骸副词条可出现的数值范围。
  4. 鳴潮 Wiki* — 音骸/厳選と確率：副词条离散档位与公开概率整理。
  5. chuan-hane/wuwa-damage-calculator 与 devyur/Wuwa-rotation-calculator：用于交叉检查社区开源实现的乘区组织方式。
重要：本工具是非官方理论计算器。鸣潮并未提供一套面向玩家的官方完整计算器；公式与词条资料来自社区实测、Wiki 与开源工具的交叉验证。版本更新、新角色的“特殊倍率/独立乘区/异常效果”可能需要单独建模。工具不把未验证机制伪装成官方结论。

核心公式

属性 = 当前总属性 - 旧声骸贡献 + 新声骸贡献 + 基础属性 × Buff% + 固定 Buff
期望暴击 = 1 + min(CR, 100%) × (CD - 100%)
伤害加成 = 1 + 全局/属性加成 + 对应攻击类型加成
Amplify = 1 + 全局 Amplify + 对应攻击类型 Amplify

单窗口换装倍率 = CandidateFactor / CurrentFactor
整轮换装倍率 = Σ(当前窗口伤害占比 × 单窗口换装倍率)
副词条边际收益 = 完整候选 / 去掉该条后的候选 - 1

“伤害占比加权”让工具可以精确处理 Buff 覆盖与重叠，而不需要假设 Buff 相互独立。若你填的是实战/完整模拟器得到的当前伤害占比，则技能倍率、防御、抗性、独立乘区等已经隐含在权重里。
